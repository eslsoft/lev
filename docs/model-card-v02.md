# Lev-4B v0.2：英语开放问题判断研究模型

已完成真实 GPU 训练、开发集选择、独立校准、修正后的测试评估与直接问法回归。推荐研究检查点为 **`lev-4b-v0.2`**；模型未发布或部署。全部原始产物和失败的数据质量检查均保留。

## 输入与输出

输入是英语材料、必要上下文和开放的自然语言真假问题；`kind` 只作统计，不限制可接收的问题类别。输出由 Kev 的 `noul` 布尔决策头给出 `false / true` 概率，不生成回答或解释文本。

`true` 表示**所提问题为真**，并不总是“批准词条”。例如，问题若是“这里有错误吗？”，true 就表示有错误。所有评测样本都是 partial 判断，不能据此宣称已验证完整词条审核。

## 修正后的主测试：932 个判断

| 模型 | 正确数 / 判断数（准确率） | 类别宏平均 |
|---|---:|---:|
| 原始 Kev | 621 / 932（66.63%） | 57.05% |
| Lev v0.1 | 619 / 932（66.42%） | 56.14% |
| Lev v0.2 | 791 / 932（84.87%） | 88.28% |

v0.2 相对 v0.1 提升 **18.45 个百分点**，相对原始 Kev 提升 **18.24 个百分点**。按声明的词族、文档、语法构式和对话分组进行 2,000 次配对 bootstrap，v0.2 相对 v0.1 的提升区间为 **[13.89, 23.14] 个百分点**（95%，固定 seed 42）。测试共有 595 个声明分组，与完整公开词形闭包的分组数量一致；少量语法构式和公开语料污染风险仍限制总体推断。

| 测试任务 | 原始 Kev | Lev v0.1 | Lev v0.2 |
|---|---:|---:|---:|
| 语法可接受性 | 91 / 160（56.88%） | 95 / 160（59.38%） | 106 / 160（66.25%） |
| 会话含义（本轮未训练） | 391 / 492（79.47%） | 392 / 492（79.67%） | 412 / 492（83.74%） |

三个模型均完成 932 / 932 个判断，零缺失、零截断、零拒绝。v0.2 的假阴性为 62、假阳性为 79，均按**问题本身的真假标签**计算。最弱项仍是语法可接受性（66.25%），会话含义也仍有 80 个错误。

Brier：原始 Kev 0.19980、v0.1 0.28524、v0.2 0.12261。前两个模型使用原生温度，v0.2 使用本次独立校准，因此这些概率指标同时包含模型和校准方案的差异；0.5 阈值下的准确率不受正温度缩放影响。

## 数据与隔离修正

最终研究数据版本为 `artifacts/en-general-005`：4,309 条请求、6,478 个判断，全部为 partial。训练实际使用 004；005 的 train、development、calibration 导出文件与 004 **逐字节一致**，仅修正一条测试请求。保持已训练权重是有证据的复用，不需要重复训练相同输入。

| 分区 | 请求 | 判断 |
|---|---:|---:|
| train | 2,798 | 4,424 |
| development | 424 | 590 |
| calibration | 323 | 532 |
| test | 764 | 932 |

来源：Open English WordNet 2025、英语 Wiktionary/Kaikki、UD English EWT、CMUdict、BLiMP；BIG-bench implicatures 仅用于测试，没有加入训练或校准。所有 6,478 个判断的来源字段、原始标签或确定性推导、肯定/否定转换均已逐项核验。它们是 `source_labeled` / `source_derived` 研究标签，不是假冒的 Lev 独立人工金标准。

独立审计发现原 004 中 good/well 共享 better/best 词形，首个词形归属的 alias 映射漏掉另一个归属，造成一条测试请求的两个判断与训练词族相连。已修复生成器、增加回归测试，并按来源资格和固定哈希从 117 个候选中选出一条独立 UD 请求替换。替换脚本不读取预测或分数；被替换记录和原结果完整保留。

**该修正发生在第一次 004 测试之后，005 不是全新独立复现。** 三个模型的 930 个未变判断，其概率和判定均逐项完全一致。004 原结果：Kev 621 / 932，v0.1 619 / 932，v0.2 790 / 932；005 为 621、619、791。没有挑选重跑中的最好结果，修正依据是预先要求的词族隔离，而不是预测表现。

完整公开词形/派生关系、所选关系端点、目标词和 UD 文档闭包审计：005 零跨分区违规；002 回溯检查也通过。普通句子中的偶然共用词汇不作全局隔离，不能声称“所有词汇互不重叠”。详见[修正协议](experiments/en-general-005.md)及[训练协议](experiments/en-general-003.md)。

## 校准与训练

校准使用 532 个独立分组判断，固定 121 点对数网格 0.25–4、micro NLL，得到 **T = 2.193650**，未触及边界。阈值固定为 0.5。新校准文件绑定 005 manifest 和全部检查点文件哈希；旧校准文件没有改写。跨路径搬迁后的校准校验已通过。这不是新任务/新领域的校准保证。

初始化于 `jaredpalmer/kev-4b@139fdd94f1b6a6ad80cc15e08fcb99cac885a101`；基础为 `Qwen/Qwen3.5-4B-Base@1001bb4d826a52d1f399e183466143f4da7b741b`；Kev 引擎提交为 `1f04cfa28e6a708485b28a9585010b9e436b776e`。没有修改 Kev checkout。

LoRA rank 16，约 33.8M 可训练参数；2 epochs、lr 1e-5、batch 1、accumulation 8、seed 42、gradient checkpointing。A100-80GB，训练 bf16 autocast / fp32 基础权重，评测为 Torch fp32。可选优化 CUDA 内核未安装，实际使用上游 PyTorch 实现。

真实训练：5,596 / 5,596 次请求处理、700 个优化器步骤、1,281,674 forward tokens，零截断、零拒绝，梯度有限。梯度训练耗时 4549.89 秒（75.83 分钟），峰值设备分配 18,695,086,080 字节、主机 RSS 31,470,919,680 字节。资源测量仅适用于这批短上下文样本。

## 能力边界与归属

这是英语研究检查点，不是任意英语问题都可靠的证明。语法仍有明显误差；旧直接问法的语法子集有回退；词源、语域、搭配、地域变体、长文档、完整词条和其他语言尚未全面验证。当前新测试没有新的 Wiktionary 词汇分析组，旧开发集的词汇分析回归仅 22 个判断。

公开来源可能进入基础模型或上游 Kev 的预训练/微调数据；没有证明不存在上游污染。来源标签也可能有错误或任务约定差异。没有独立专家生产验收，不把来源一致性审计当作语言事实的独立裁定。

保留 Qwen、Kev 及各数据来源的归属和许可证；不把所有数据笼统重新许可为代码的 Apache-2.0。Modal 训练、评测与产物读取使用已授权的开发者工作区/身份 `saltbo`，因为 Realmroot 没有匹配的 Modal 集成。仅执行研究计算，未部署或公开发布模型。

本地 36 项 unittest 通过，ruff 通过；这些检查与实际 GPU 训练/评测证据分别保存。训练及最终运行的客户端曾提示最终日志读取超时，服务端各阶段均成功，原始日志、状态和下载后的报告已独立核验；没有因此重新训练。
