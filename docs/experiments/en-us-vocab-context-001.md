# 独立语境补充：35,000词目标的WiC子集

此方案在读取任何补充集模型成绩前固定。目标是增加真实双语境词义判断，不能把词典库存判断当成全面的语境能力。本包不替换或改写`en-us-vocab-35000-v3`，也不修改正在训练的v0.4或其开发选择规则。

使用已下载的官方WiC v1.0原包及其T/F标签，保留原始train/dev/test来源标识。标签来自WiC发布方，不宣称Lev独立专家裁定。只选择冻结35,000词表中的目标词。所有已用于Lev历史训练或评估、以及当前联合包任一分区的已知词族均排除；词族闭包沿用词形、派生、拼写变体及相同上下文连接。排除与重复记录全部写入审计。此排除不能证明基础模型预训练未见过公开WiC。

本包仅test，全部partial，不可进入训练四分区入口。每词保留全部符合条件且不重复的来源题；按原35,000词排名排列，另保留原排名，子集使用连续rank以兼容逐词评分。覆盖报告同时列出原35,000词中无可用语境题的词数，不能用子集准确率冒充全部35,000词语境准确率。

源标签只进入训练格式的label和元数据；模型state只包含词、两段上下文、目标词偏移和WiC语义粒度说明。全部使用同一个开放自然语言问题：两个标记用法是否具有相同含义。原始数据字节、词表、排除清单、构建代码及来源许可均冻结哈希。

只有既定开发门槛选定模型并独立校准后才允许模型评分；阈值0.5。使用逐词全部已排定题通过率、判断准确率、误拒、漏放、缺失数，并按原生来源分区区分公开数据接触风险。不根据本补充集成绩挑模型或修改阈值。

本包采用来源WiC的CC BY-NC 4.0限制；词表选择来源另有CC BY-NC-SA 4.0限制。仅本地非商业研究，不发布数据或模型。构词、搭配、语域等仍需另补，本包不能宣称这些能力已覆盖。
