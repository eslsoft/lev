# Lev-4B v0.1：英语通用判断研究版

状态：首轮完整训练、检查点重新加载、校准和留出评测均成功。研究检查点已下载，未发布模型或部署服务。原始产物位于 `runs/modal-lev-general-20261021-01`；全部模型文件哈希与云端记录一致。

## 模型与接口

- 用途：给定英语语言材料、必要上下文和任意自然语言判断问题，输出真假概率。类别是数据统计标签，不限制问题输入。
- 输出：Kev `noul` Boolean 决策头；不生成回答、解释或修改建议。
- 基础：Qwen3.5-4B-Base revision `1001bb4d826a52d1f399e183466143f4da7b741b`。
- 初始检查点：Kev-4B revision `139fdd94f1b6a6ad80cc15e08fcb99cac885a101`。
- Kev 源码：`1f04cfa28e6a708485b28a9585010b9e436b776e`，由现有 checkout 打包，不修改上游。
- LoRA rank 16，约 33.8M 可训练参数；2 epochs、lr 2e-5、batch 1、accumulation 8、seed 42。实际参数与原始命令保存在各阶段 `job.json` 和 `training_config.json`。
- CUDA bf16 autocast、fp32 基础权重；A100-80GB。Kev Python 固定 3.13.8，依赖遵循 Kev 锁文件。
- 适配器不是完整基础模型；推理仍需要固定版本的 Qwen 基础权重及 Kev 引擎。

## 数据

使用 `en-general-research-v1` 自由问题契约，冻结版本 `en-general-002`：1,006 条 partial 请求、1,724 个判断、397 个分组。真假标签各 862 个。

| 分区 | 请求 | 判断 |
|---|---:|---:|
| train | 581 | 970 |
| development | 126 | 204 |
| calibration | 206 | 388 |
| test | 93 | 162 |

来源包括 Open English WordNet、英语 Wiktionary/Kaikki、UD English EWT、CMUdict 和 BLiMP。版本、使用权限、转换规则、采样排除记录和分区方法见实验协议。标签为公开来源标签或确定性推导，**没有伪装成 Lev 独立人工裁定**。整个产物标为 `research_only`，不能作为已验收生产金标准。

词汇任务按词族、显式词形、派生关系与选中关系端点归组；UD 同时按文档归组；BLiMP 按语法现象留出。普通句子中偶然共用的词不保证全局隔离。来源可能已出现在基础模型的预训练数据中。

## 使用边界

- 这是小规模研究试验，不是对任意英语问题都可靠的保证，也没有独立专家验收。
- 当前覆盖语义关系、语法可接受性、句法角色、词汇分析和给定发音的重音判断；未全面验证语用、语域、词源、地域变体、长文档或其他语言。
- 固定问句模板较少；尚无充分证据证明对任意新问法、复杂任务组合的泛化能力。
- 全部数据为 partial，不提供完整词条审核成绩。
- 点估计来自小型、相关的来源样本，不是总体准确率保证。概率校准不提高 argmax 正确率。
- 当前没有生产部署或发布流程执行；人工裁定、真实贡献旁路测试与来源权利检查仍是生产验收要求。
- 不把模型文件大小当作延迟、吞吐或完整上下文显存保证。训练资源测量与推理性能是不同指标。
